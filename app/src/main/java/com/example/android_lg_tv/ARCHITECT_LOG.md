# ЖУРНАЛ АРХИТЕКТОРА (LG_TV_CC2340)

## Утвержденная BLE-логика управления

### 1. Потоковая Громкость (Dynamic Hold)
* **ACTION_DOWN:** Мгновенный вылет пакета СТАРТ (Маркер = 100). Фиксация `volumeStartTime`. Блокировка дисконнектов.
* **ACTION_UP:** Вычисление дельты времени удерживания кнопки.
    * *Режим А (Длинный жим):* Если удержание > 200 мс, Маркер = 0 улетает мгновенно по факту отрыва пальца.
    * *Режим Б (Короткий клик):* Если удержание < 200 мс, отправка Маркера = 0 сдвигается по Handler на остаток безопасного окна (200 мс минус дельта), гарантируя ИК-чипу платы время на инициализацию.

### 2. Сингл-шот команды (Mute, ON)
* Текущий статус: Работают по OnClickListener (вылет пакета строго на отпускание пальца).
* План: Перевод на TouchListener для мгновенного выстрела по ACTION_DOWN (в обработке).

## Будущая модернизация железа (Ревизия 2)
* Замена транзистора BSS138 на мощный AO3400 (5А) для форсирования дальности ИК до 10–15 метров.
* Уменьшение резистора R4 до 1–2 Ом (обеспечение импульсного тока 0.5–1 А).
